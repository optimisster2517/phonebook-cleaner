**Рефакторинг адресной книги (Regex & Python)**

**📖 О проекте**

Скрипт предназначен для автоматической чистки и систематизации контактных данных из CSV-файла. Он превращает «сырую» адресную книгу с хаотичными записями в структурированную базу данных, исправляя ошибки распределения ФИО, форматы телефонов и удаляя повторяющиеся контакты.

**🎯 Ключевые функции**

* **Сортировка ФИО**: Автоматический перенос фамилий, имен и отчеств в соответствующие столбцы.
* **Стандартизация номеров**: Приведение любых форматов записи телефонов к единому стандарту: +7(999)999-99-99.
* **Слияние дубликатов**: Поиск и объединение нескольких записей об одном человеке в одну максимально полную карточку.

**🛠 Технический стек**

* **Язык**: Python 3.x
* **Библиотеки**: re (регулярные выражения), csv, collections.
* **Файловая структура**:
  + phonebook\_raw.csv — исходный файл с ошибками.
  + phonebook.csv — итоговый очищенный файл.

**⚙️ Логика обработки данных**

**1. Работа с именами (строковые методы)**

Алгоритм собирает данные из первых трех колонок в одну строку и заново распределяет их по полям.

**Важно:** Согласно условию задания, для обработки ФИО используются стандартные методы строк (например, .split()), а не регулярные выражения.

**2. Форматирование телефонов (Regex)**

Скрипт распознает и преобразует любые варианты написания с помощью регулярных выражений.

**Примеры трансформации:** | Исходный формат | Результат обработки | | :--- | :--- | | 8 (495) 888-88-88 | +7(495)888-88-88 | | +7 999 1234567 доб. 12 | +7(999)123-45-67 доб.12 | | 89991234567 | +7(999)123-45-67 |

**3. Дедупликация и слияние**

Программа группирует записи по связке **«Фамилия + Имя»**. Если найдено несколько совпадений, данные объединяются: пустые поля основной записи дополняются информацией из найденных дублей.

**🚀 Инструкция по запуску**

1. Убедитесь, что исходный файл phonebook\_raw.csv находится в папке со скриптом.
2. Запустите программу через терминал:



python phonebook\_solution.py

1. Результат будет автоматически сгенерирован в файле phonebook.csv.

**📂 Описание функций в коде**

* fix\_name\_fields(contact) — отвечает за корректное распределение ФИО по ячейкам.
* normalize\_phone(phone) — превращает текстовый хаос в стандартный номер телефона через Regex.
* merge\_contacts(contacts) — агрегирует данные и удаляет лишние повторы в списке.
